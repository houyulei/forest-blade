森之刃：三剑、剑技与剑魔法
更新：2026-10-21

当前版本以本文件为准。替换先前“旅行剑 + 火核 + 脚下爆炎”的战斗方案。
三把剑已全部开放，方便直接比较和试玩；没有新增肉鸽、波次或随机三选一。
仍通过固定地图掉落素材、铁匠强化、出售素材来积累常驻成长。

一、参考《伊苏6》的部分
官方介绍将三剑区别概括为：风剑在连击后按时机接旋风，火剑偏重与蓄力攻击，雷剑偏快刺与雷电突进；三者各有剑魔法。
来源：[S1] https://www.worldofys.com/napishtim/ （Elemental Blades）
这是在本项目 2.5D 固定镜头中的实现：原创武器名、少年角色、动作图集、特效与数值，并非逐帧复刻原作。
本版使用 K 作为直接施展剑技的入口，同时保留风剑 J 接续、火剑长按 J 的武器专属操作。

二、操作
1：苍岚剑（风）　2：焰锋大剑（火）　3：鸣雷长枪（雷）。I 装备界面也可切换。
J / 鼠标左键：普通攻击。火剑短按为普通斩击，持续按住可蓄力，松开释放。
K：剑技。风剑直接起舞；火剑按住蓄力、松开释放；雷剑突进。
Q：剑魔法，当前剑的魔法槽满 100 时释放。
WASD 移动；空格跳跃；Shift 冲刺；E 与附近铁匠对话；I 装备；Esc 关闭；R 重返地图。
出招、蓄力、受击或冲刺期间不能直接换剑；收招后可切换。

三、苍岚剑：连斩 → 回风连舞 → 苍岚龙卷
普通攻击：三连斩，时长 0.34 / 0.37 / 0.52 秒，使用原有横斩、回斩、重劈三套图集。
基础攻击 10，每级强化 +2；三段附加伤害分别为 0 / 1 / 4。

剑技“回风连舞”：
- 三连斩结束后有 0.38 秒窗口，继续按 J 进入旋身攻击。
- 之后每段结束有 0.32 秒窗口继续按 J，最多接五段；旋身后半段可提前按 J 预约下一段。
- 每段 0.34 秒，使用独立 16 姿势整圈旋身图集，并从当前面朝方向开始旋转。
- 可用 K 直接起舞；J 接续强调点按节奏，不是按住自动连发。
- 对近身 1.3 单位范围内目标斩击，同时发出向前移动的旋风，前进 4.7 单位。
- 每段每个目标最多命中一次，近身斩击与同段飞行旋风共享命中记录，伤害 9 + 强化级别 × 2。
- 达到五段后有 0.75 秒剑技间隔；会受伤、可以被打断，不是持续无敌。

剑魔法“苍岚龙卷”：
- 在身前近处生成持续 2.35 秒的大龙卷，范围半径 2.15。
- 最多六次伤害脉冲，间隔 0.38 秒；每次伤害 7 + 该剑强化级别。
- 伤害朝龙卷中心施加拉扯方向，实体墙体会遮挡作用。

四、焰锋大剑：重斩 → 蓄焰斩 → 贯焰火球
普通攻击：比风剑更重、更慢，0.50 / 0.54 / 0.70 秒，使用双手红钢大剑的独立低位发力图集。
基础攻击 18，每级强化 +2；三段附加伤害分别为 0 / 4 / 12。

剑技“蓄焰斩”：
- 按住 K，或从待机开始按住 J / 左键，稳住重心、双手举剑过顶蓄力。
- J 按下后在 0.18 秒内松开，会转换为普通重斩；K 短按可以释放低蓄力火焰。
- 蓄力时站定，可以用移动方向调整面朝；蓄力 1 秒达到满威力，持续到 1.2 秒会自动释放。
- 松开后向前斩出，释放动作 0.40 秒，动作进度 28% 时发出沿地面前进的火焰。
- 火焰可贯穿多个敌人，每个敌人只命中一次，遇实体障碍停止，不会穿墙或隔墙伤害。
- 伤害：12～30（按蓄力比例）+ 该剑强化级别 × 3；距离：2.5～6.4 单位。
- 精炼结晶额外 +6 伤害、+0.8 距离，并将火焰半径从 0.52 扩至 0.62。
- 蓄力和释放均非无敌；受伤会打断尚未释放的火焰，不会留下延迟爆炸。
- 已发出的火焰独立前进。旧脚下爆炸、火圈和旧“Q 爆炎斩”不再参与游戏。

剑魔法“贯焰火球”：
- 向前发出大火球，飞行 9 单位、贯穿多个目标；每个目标命中一次，遇墙停止。
- 伤害：38 + 该剑强化级别 × 5；精炼结晶再 +8。
- 使用独立绘制的火球动画，朝屏幕投影方向转动，保持火球头部与前进方向一致。

五、鸣雷长枪：快速连刺 → 雷光贯突 → 跃雷连锁
普通攻击：三段直刺，0.24 / 0.22 / 0.32 秒。使用独立双手长枪图集和直线刺击光迹，命中角度比斩击更窄。
基础攻击 8，每级强化 +2；三段附加伤害分别为 0 / 0 / 3。
普通刺击命中积累一格电能，最多三格。电能保存在本次地图内，切剑不清空。

剑技“雷光贯突”：
- K 向前突进；三格电能时强化，消耗全部电能。
- 普通突进约 1.9 单位，伤害 15 + 该剑强化级别 × 2。
- 满电突进约 3.7 单位，伤害 28 + 该剑强化级别 × 2。
- 积满三格后按 K 主动释放强化贯突。J 保持基础三连，不自动突进。
- 使用真实角色移动与实体碰撞，不能穿过墙体；沿途每个目标最多命中一次。
- 电光包裹身体、拖出雷电残迹；只有突进生效段有短暂无敌，前摇可受伤。
- 无敌不会令人物不断闪没；受击闪烁与剑技无敌已分开。

剑魔法“跃雷连锁”：
- 从附近目标开始，依次在可见敌人间跳跃；第一跳距离 5.5，后续每跳 3.4 单位。
- 优先未命中目标，再允许回跳；最多六跳，每个目标最多两次，无法越过实体遮挡。
- 每跳伤害 14 + 该剑强化级别 × 2。
- 单个孤立敌人不会凭空反复弹射。它擅长多目标，火球更适合直线路径。

六、资源、强化和旧存档
三剑各有独立魔法槽，上限 100，每次 Q 消耗一整槽。只有当前剑每秒恢复 2，普通攻击命中恢复 8。
切剑不会补满旧剑魔法槽。K 剑技不消耗剑魔法，改由蓄力、点按窗口、连刺电能和出招空隙约束。
初次进入/重返地图三剑满槽。与铁匠选择“休息片刻后离开”补满生命与三剑魔法。
魔法槽、电能、当前动作和临时特效不写入永久存档。

三剑独立强化至 +3；铁匠强化当前装备的剑。配方维持：
+1：铁矿 2、怪物牙 1、金币 12。
+2：铁矿 4、怪物牙 2、守卫碎片 1、金币 30。
+3：铁矿 6、怪物牙 3、守卫碎片 2、金币 60。
精炼焰锋大剑结晶：铁矿 2、怪物牙 1、守卫碎片 1、金币 25；只做一次，永久增强火剑。

保留原 user://adventure-save-v1.json 文件路径，内部版本提升为 2，包含 equipped_sword 与三剑等级。
旧版旅行剑强化迁移到焰锋大剑，旧火核转为其精炼状态；金币与材料完整保留。
读取旧存档后的第一次保存会先创建 .v1.bak 原文件备份，再原子替换正式存档。
进度事务在保存失败时回滚。打开装备期间，角色、飞行攻击与伤害都暂停。
