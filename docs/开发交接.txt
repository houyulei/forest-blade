身份、名称与基础攻击：scripts/sword_arsenal.gd。

未强化三段普攻：
  苍岚剑 wind：伤害 10 / 11 / 14；时长 0.34 / 0.37 / 0.52 秒。
  焰锋大剑 fire：伤害 18 / 22 / 30；时长 0.50 / 0.54 / 0.70 秒。
  鸣雷长枪 thunder：伤害 8 / 8 / 11；时长 0.24 / 0.22 / 0.32 秒。
时长不包含命中停顿；强化每级给该武器每段普攻加 2。
大剑重而慢，长枪快而远；不要只换贴图而把节奏、伤害、范围改成相同。

风剑：三连斩后继续点 J 可接旋舞，最多五段；K 可直接起舞。
  每段旋舞 0.34 秒，使用独立 16 姿势图集；Q 是苍岚龙卷。
大剑：肩上斜劈 → 反向横斩 → 过顶重劈，避免从脚下反常抬起作为主要重斩。
  范围 2.15 / 2.30 / 2.50，第三击收窄为前方重劈。K 按住蓄力、松开释放。
  待机按 J 不足 0.18 秒松开转普攻，已等待的时间计入前摇。
  续段窗口内按 J 必须直接接下一击，不能重新进入蓄力导致三连重置。
  满蓄力 1 秒，持续至 1.2 秒自动释放；蓄力姿势为双手过顶，释放后向前出火焰。
  Q 是贯焰火球；旧“Q 脚下爆炎”不再参与当前战斗。
长枪：平刺 → 低刺 → 踏步贯刺，三段都必须保留为基础动作。
  范围 2.80 / 2.95 / 3.15，左右各宽 0.36 / 0.36 / 0.42，为前方窄直线。
  每次普攻首次命中最多积一格电，最多三格；K 主动雷光贯突，满电强化。
  连按 J 不自动变成突进。Q 是跃雷连锁，偏多目标，不应让孤立敌人无限回弹。

共同约束：
一次普攻对同一目标只结算一次；多目标仅首次接触触发本次角色命中停顿。
攻击开始保存武器和伤害快照；受击打断动作并清除输入缓存。
攻击前摇不允许随意取消，后摇过取消点可冲刺；出手可进身，收招不持续滑行。
火与雷排除背后目标；高度和实体障碍影响判定，不能隔墙打击。
雷贯突使用真实角色移动与碰撞，不能穿墙；只有生效段短暂无敌。
动作、命中和刀光共用时间轴，不要各写一套互不一致的阈值。
三武器各有 0—100 魔法槽：当前武器每秒恢复 2，普攻命中恢复 8，Q 消耗满槽。
切换不凭空补槽；进入地图或铁匠休息会补满，临时槽与电能不写永久存档。

八、动作检查台与画面验收

  ./tools/animation-lab
会从 Godot 导出当前映射和时间轴，再在 macOS 浏览器打开 tools/animation-lab.html。
也可直接打开 HTML 离线查看已随项目保存的 tools/animation-lab-data.js。
修改脚本时间轴或图集后需要重新导出，不要把旧数据当作当前结果。
检查台覆盖三武器、11 类动作、四方向、每段 121 个采样，共 15972 样本。
支持：慢放、暂停、1/60 秒单步、关键姿势跳转、四向并排、叠影、脚底网格。
握点标注为手工标注，存浏览器 localStorage，可导出 JSON；不是自动识别正确握法。
按整段动作包围盒稳定取景；不要逐帧自动缩放，避免掩盖人体变大变小和脚底跳动。
检查台播放真实图集关键帧，不用虚构补帧掩饰不完整动作。
检查台不模拟完整战斗位移、相机遮挡、碰撞、敌人反应与特效，最后仍要回到实机。

画面核对顺序：
  静态握持和人体比例 → 双腿完整循环 → 三连起承转合 → 四向与镜像 → 实机命中和环境。
  长枪双手在后段、前后手有间距，不能抓枪杆正中；持械跑步不能混成连续刺击。
