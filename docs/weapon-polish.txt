武器造型与普攻打磨

当前三种武器：苍岚剑（风）、焰锋大剑（火）、鸣雷长枪（雷）。
按 1 / 2 / 3 切换。J / 左键普攻，K 武器技，Q 满槽元素魔法。
火大剑仍支持从待机按住 J 蓄力（续段窗口内 J 直接接下一击，K 可在收招后蓄力）；短按累计的时间计入普通攻击前摇，避免重复等待。

未强化普攻（三段分别列出）：
火大剑：伤害 18 / 22 / 30；出招 0.50 / 0.54 / 0.70 秒。
  正前宽扇面，半径 2.15 / 2.30 / 2.50；第三击收窄为约 77 度的前方重劈，换取高伤害。
  两手握长柄：肩上斜劈 → 反向横斩 → 过顶重劈。第三击蓄势更长。
  蓄力也改为双手举过头顶，松开后向前重劈并释放贯穿火焰。
  命中停顿 0.045 / 0.050 / 0.075 秒，保持重量感。
雷长枪：伤害 8 / 8 / 11；出招 0.24 / 0.22 / 0.32 秒。
  正前窄直线，长度 2.80 / 2.95 / 3.15，左右各宽 0.36 / 0.36 / 0.42。
  双手分开握枪杆：平刺 → 低刺 → 踏步贯刺；第三刺踏进更远。
  每次普攻命中最多积一格电，最多三格；K 主动释放雷光贯突，满电时强化。
  连按 J 不再自动转成突进，持续基础三连。
  命中停顿 0.012 / 0.012 / 0.022 秒，避免快攻被卡顿拖慢。
出招时间不含命中停顿；每级强化对该武器各段伤害均加 2。
风剑原有三连斩、旋身连舞和龙卷保留。

共同规则：
- 命中与完全出剑/出枪关键姿势对齐，刀光/枪芒使用同一时间轴。
- 一次普攻对每个目标只伤害一次；多人命中只在第一次接触时触发角色停顿。
- 火与雷不攻击背后的贴身目标；场景实体遮挡伤害；长枪侧向不再随距离无限变宽。
- 出手时小步进身，收招不滑行。后摇允许闪避取消，前摇不能直接取消。
- 当前攻击保存伤害快照；受击会中断攻击并清除缓存输入。
- 火大剑向左使用一致朝向的镜像侧身姿势，修正源图中途转向的问题。

旧 greatsword-attack 图集仅保留历史来源，不再接入角色动作。
整理只做透明区切帧、等比缩放、脚底定位和相邻连段关键帧衔接。
下一击起手复用上一击最后一帧；等待续段输入时保留上一击收势，不跳回待机。
大剑左向采用右向镜像，避免源图在释放时转向相反方向。
测量深色头发至脚底的身体高度，抬高武器不再导致人物本体缩小。
图集每格 640，脚底基线 560，显示偏移 240；本体尺度维持 ActorSizes，留白容纳长武器。
移动使用各自持械跑步图集；跳跃、冲刺和受击保持装备武器，不再变回短剑。
跳跃借用持械跑步中的屈膝姿势，尚非另绘完整空中动作；当前仍为四方向六关键帧表现。
